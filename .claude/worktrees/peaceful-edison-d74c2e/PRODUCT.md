# PRODUCT.md — Brachas with Rimon

**Register:** product (app UI serving a daily practice) with brand-warm skin.

**Users:** Jewish adults (students → professionals) building a consistent
bracha practice; friendly to teens/kids but never childish. They use it at
mealtimes, on a phone, often one-handed, sometimes at a Shabbat-adjacent pace.

**Purpose:** photograph a meal → learn the right blessings in the right order
→ close the meal properly. A learning aid with soul, never a posek —
"consult a rabbi" is a load-bearing sentence on every screen.

**Brand voice:** warm, literate, unhurried. A wise friend, not a gamified
slot machine. Rimon (the pomegranate) is the personality: curious, gentle,
occasionally playful; he never nags.

**Anti-references:** Duolingo's pressure loops (guilt streaks, ad walls),
generic SaaS gradients, sterile "Jewish app" clip-art (menorahs everywhere),
childish sticker aesthetics.

**Strategic principles:**
1. Halachic data only from chabad.org / brachos.org / oukosher.org; liturgy
   may add licensed public-domain siddur text. Claude vision only maps to DB keys.
2. Human-in-the-loop always (confirm screen, shiur checkboxes, "done eating?" ask).
3. Local-first; every network feature degrades gracefully.
4. Rimon appears on every screen, alive (motion loops), interactive (boop).
